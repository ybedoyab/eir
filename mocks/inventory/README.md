# Synthetic pharmacy inventory

Fictional stock levels for the Supply & Replenishment fleet module. No real
procurement data, no real prices, no real suppliers.

`MED-ENOX-40` is seeded below its reorder point on purpose: it is the demo
stock-out. `MED-METF-850` sits just below its reorder point so the scheduler is
seen handling a queue rather than a single case.
